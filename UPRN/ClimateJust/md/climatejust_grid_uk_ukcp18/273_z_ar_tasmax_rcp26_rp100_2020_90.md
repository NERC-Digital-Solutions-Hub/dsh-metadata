#### Description

This **"All-Relative" Z-score** converts the near-term high-end projection for 1% annual-probability heat events into a standardized relative score. It identifies where current relative extreme heat exposure could be significantly above the dataset average if global climate sensitivity is high.

* **Assumption:** Higher relative maximum temperatures equate to an increased exposure risk, driving up geographical disadvantage in neighbourhoods containing sensitive populations.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** Statistically, actual temperatures during such an event are 90% likely to be below these high-end values for this specific scenario and period.
* **Data Source:** Standardized from **UKCP18** probabilistic climate projections.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
