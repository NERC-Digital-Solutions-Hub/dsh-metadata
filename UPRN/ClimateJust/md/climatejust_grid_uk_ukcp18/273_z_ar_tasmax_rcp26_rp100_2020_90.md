The field 'Summer extreme Relative Z-score maximum temperature low emissions 100 year return period 2020 90th percentile' (internal name z_ar_tasmax_rcp26_rp100_2020_90) represents the standardized high estimate of current temperatures during a 1-in-100 year extreme heatwave under RCP 2.6.
Description
This "All-Relative" Z-score converts the near-term high-end projection for 1% annual-probability heat events into a standardized relative score.
 It identifyies where current relative extreme heat exposure could be significantly above the dataset average if global climate sensitivity is high.
Assumption: Higher relative maximum temperatures equate to an increased exposure risk, driving up geographical disadvantage in neighbourhoods containing sensitive populations.
Vulnerability Dimension: Standardized input for Hazard Exposure.
Caveat: Statistically, actual temperatures during such an event are 90% likely to be below these high-end values for this specific scenario and period.
Data Source: Standardized from UKCP18 probabilistic climate projections.
