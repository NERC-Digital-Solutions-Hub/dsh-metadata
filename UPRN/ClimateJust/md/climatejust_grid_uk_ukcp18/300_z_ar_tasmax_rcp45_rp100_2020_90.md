### Summer extreme Relative Z-score maximum temperature moderate emissions 100 year return period 2020 90th percentile

#### Description

This metric is an **"All-Relative" Z-score**, meaning it is calculated using the mean and standard deviation across all scenarios and time periods (2020s, 2050s, 2080s) in the database. It converts the 90th percentile (high estimate) of current (2010–2030) daytime maximums during an exceptionally rare 1% annual-probability extreme event into a standardized relative score. This allows for direct comparison between the most extreme current hazard risks and all future scenarios in the database.

* **Assumption:** Higher relative maximum temperatures equate to an increased exposure risk, which can cause severe well-being losses in sensitive communities.
* **Vulnerability Dimension:** Standardized input for the **Hazard Exposure** assessment.
* **Caveat:** Standardized scores highlight relative risk across the dataset but do not reflect the absolute peak Celsius temperatures reached during an event.
* **Data Source:** Standardized from **UKCP18** probabilistic climate projections.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
