#### Description

This **"All-Relative" Z-score** converts the near-term high-end projection for 5% annual-chance heat events into a standardized relative score. It identifies neighbourhoods facing acute current extreme heat exposure relative to the entire dataset average if the climate system is sensitive to greenhouse gases in a world of rising global emissions.

* **Assumption:** Higher relative maximum temperatures equate to an increased exposure risk, driving up geographical disadvantage in sensitive communities.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** High estimates represent a scenario that is only 10% likely to be exceeded according to the probabilistic model.
* **Data Source:** Standardized from **UKCP18** current period projections.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
