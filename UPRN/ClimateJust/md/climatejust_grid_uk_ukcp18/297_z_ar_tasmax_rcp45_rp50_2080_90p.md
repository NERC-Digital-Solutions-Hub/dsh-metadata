#### Description

This **"All-Relative" Z-score** standardized the high-end projection for extremely rare 2% annual-chance heat events at the end of the century. It identifies geographical areas potentially facing catastrophic late-century relative extreme heat hazards relative to the entire dataset average if the climate responds aggressively.

* **Assumption:** Neighbourhoods with the highest relative maximum temperatures face the greatest challenge in protecting sensitive residents from catastrophic health impacts.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** There is only a 10% probability that actual temperatures during such an event would exceed these values.
* **Data Source:** Standardized from **UKCP18** late-century maximum temperature projections.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
