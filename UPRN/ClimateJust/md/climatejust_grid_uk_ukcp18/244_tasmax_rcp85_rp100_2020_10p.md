#### Description

This metric evaluates **Hazard Exposure** for a "100-year return period" event—a temperature so extreme it has only a 1% annual probability of occurring. It provides the **10th percentile** low estimate for the 2020 window (2010–2030), mapping the minimum expected severity of these extremely rare events for communities today in a world tracking towards very high emissions.

*   **Assumption:** Higher extreme temperatures indicate an increased exposure risk, which can lead to severe losses in community well-being.
*   **Vulnerability Dimension:** This informs the **Hazard Exposure** dimension.
*   **Caveat:** Actual current temperatures during such an event are statistically 90% likely to be higher than these values.
*   **Data Source:** Derived from **UKCP18** probabilistic projections.
