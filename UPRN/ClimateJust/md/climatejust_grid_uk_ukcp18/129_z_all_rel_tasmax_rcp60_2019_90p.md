The field **'Summer average Relative Z-score maximum temperature high emissions 2010-2030 90th percentile'** (internal name `z_all_rel_tasmax_rcp60_2019_90p`) represents the standardized high estimate of current average daily maximum summer temperatures under RCP 6.0.

### Description

This **"All-Relative" Z-score** converts the near-term high-end daytime maximum projection into a standardized relative score. It identifies where current relative daytime heat exposure could be significantly above the dataset average if global climate sensitivity is high in a world with rising greenhouse gas levels.

* **Assumption:** Higher relative maximum temperatures signify a greater potential for communities to come into contact with harmful heat events.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** This is a high estimate; actual current daytime maximums are statistically 90% likely to be below these values for this specific scenario.
* **Data Source:** Standardized from **UKCP18** probabilistic maximum temperature data.
