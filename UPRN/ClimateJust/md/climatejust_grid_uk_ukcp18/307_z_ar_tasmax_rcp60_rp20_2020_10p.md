### Summer extreme Relative Z-score maximum temperature high emissions 20 year return period 2020 10th percentile

#### Description

This metric is an **"All-Relative" Z-score**, meaning it is calculated using the mean and standard deviation across all scenarios and time periods in the database. It converts the 10th percentile (low estimate) for current (2020 window) daytime maximums during a 5% annual-probability extreme event (20-year return period) into a standardized relative score. This allows for a direct comparison between the current minimum expected extreme hazard and all future warming levels.

* **Assumption:** Neighbourhoods with higher relative scores indicate a baseline of exposure that can lead to significant well-being losses when social vulnerability is high.
* **Vulnerability Dimension:** This is a standardized input for the **Hazard Exposure** assessment.
* **Caveat:** These absolute temperature values are statistically 90% likely to be higher than recorded in this field.
* **Data Source:** Standardized from **UKCP18** current period probabilistic maximum temperature projections.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
