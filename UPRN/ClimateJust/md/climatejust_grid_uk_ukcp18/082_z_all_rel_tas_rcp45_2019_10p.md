The field **'Summer average Relative Z-score temperature moderate emissions 2010-2030 10th percentile'** (internal name `z_all_rel_tas_rcp45_2019_10p`) represents the standardized low estimate of projected summer temperatures for the current period under a moderate emissions scenario.

### Description

This **"All-Relative" Z-score** converts the 10th percentile (low estimate) for near-term (2010–2030) summer temperatures under RCP 4.5 into a standardized value. By using the mean and standard deviation across all scenarios, it highlights how these current minimums compare to the full spectrum of projected climate futures.

* **Assumption:** Positive relative scores identify current locations of relative heat hazard compared to the database average.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** This value represents the average over the 20-year window about the central year of 2020.
* **Data Source:** Standardized from **UKCP18** probabilistic projections.
