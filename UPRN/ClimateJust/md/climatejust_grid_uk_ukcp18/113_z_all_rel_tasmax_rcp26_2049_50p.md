The field 'Summer average Relative Z-score maximum temperature low emissions 2040-2060 median' (internal name z_all_rel_tasmax_rcp26_2049_50p) represents the standardized central estimate of projected mid-century average daily maximum summer temperatures under RCP 2.6.
Description
This "All-Relative" Z-score provides a standardized "likely" mid-century projection for typical daytime highs
. Standardizing across all scenarios allows these future daytime maximums to be statistically mapped on the same scale as the current baseline and more extreme future warming scenarios
.
Assumption: Positive values denote neighbourhoods where extreme relative daytime heat hazards will be higher than the dataset average
.
Vulnerability Dimension: Standardized input for Hazard Exposure
.
Caveat: Standardized scores identify geographical hotspots of hazard but mask absolute Celsius values
.
Data Source: Standardized from UKCP18 mid-century maximum temperature projections
.
