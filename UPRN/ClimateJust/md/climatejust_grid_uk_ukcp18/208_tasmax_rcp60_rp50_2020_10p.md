The field **'Summer extreme maximum temperature high emissions 50 year return period 2020 10th percentile'** (internal name `tasmax_rcp60_rp50_2020_10p`) represents the low estimate of the expected temperature at the hottest part of the day during a 1-in-50 year extreme heatwave in the current period under RCP 6.0.

### Description

This metric evaluates **Hazard Exposure** for a "50-year return period" event—an extremely rare temperature that has only a 2% annual probability of occurring (1 in 50 chance). It provides the **10th percentile** low estimate for the 2020 window (2010–2030), mapping the minimum expected current severity of these extremely rare events for communities today.

* **Assumption:** Higher extreme temperatures indicate an increased exposure risk, which can lead to severe losses in community well-being.
* **Vulnerability Dimension:** This informs the **Hazard Exposure** dimension.
* **Caveat:** Actual current temperatures during such an event are statistically 90% likely to be higher than these values.
* **Data Source:** Derived from **UKCP18** probabilistic projections.
