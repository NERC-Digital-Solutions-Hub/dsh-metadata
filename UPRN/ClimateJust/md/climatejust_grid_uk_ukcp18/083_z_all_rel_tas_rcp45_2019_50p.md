The field **'Summer average Relative Z-score temperature moderate emissions 2010-2030 median'** (internal name `z_all_rel_tas_rcp45_2019_50p`) represents the standardized central estimate (median) of summer average temperatures for the current period under RCP 4.5.

### Description

This **"All-Relative" Z-score** provides a standardized "likely" estimate of current heat hazard exposure under moderate emissions. Standardizing across all scenarios allows these baseline temperatures to be statistically mapped on the same scale as future warming scenarios.

* **Assumption:** Neighbourhoods where higher baseline exposure coincides with high social vulnerability are identified as having current heat disadvantage.
* **Vulnerability Dimension:** This is a standardized input for the **Hazard Exposure** assessment.
* **Caveat:** Values around 0 in this field denote that the LSOA's temperature is around the average for the entire database.
* **Data Source:** Standardized from **UKCP18** summer average temperature projections.
