#### Description

This **"All-Relative" Z-score** converts the near-term high-end projection for 2% annual-chance heat events into a standardized relative score. It identifies areas of high current extreme heat exposure relative to the entire dataset average across all time periods, representing a high-impact climate outcome today if the climate system is sensitive to greenhouse gases.

* **Assumption:** Neighbourhood disadvantage is statistically higher where high social vulnerability and acute relative hazards for rare events coincide.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** This high estimate represents a scenario that is only 10% likely to be exceeded according to the model.
* **Data Source:** Standardized from **UKCP18** current period projections.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
