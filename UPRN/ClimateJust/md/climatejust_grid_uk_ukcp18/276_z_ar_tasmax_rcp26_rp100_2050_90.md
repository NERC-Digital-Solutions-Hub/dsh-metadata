#### Description

This **"All-Relative" Z-score** standardized the high-end mid-century projection for 1% annual-chance extreme events against all other dataset scenarios. It identifies neighbourhoods facing acute mid-century extreme heat exposure relative to the entire dataset even in a low emissions world if global climate sensitivity is high.

* **Assumption:** Higher relative maximum temperatures signify a greater potential for residents to experience catastrophic heat-related impacts.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** This high estimate represents a scenario that is only 10% likely to be exceeded according to the probabilistic model.
* **Data Source:** Standardized from **UKCP18** probabilistic projections.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
