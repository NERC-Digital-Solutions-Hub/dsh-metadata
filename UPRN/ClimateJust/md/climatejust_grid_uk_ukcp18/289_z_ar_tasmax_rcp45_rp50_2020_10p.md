#### Description

This **"All-Relative" Z-score** converts the 10th percentile (low estimate) for the 2020 window during an extremely rare daytime heat event—one with only a 2% annual probability—into a standardized relative score. By standardizing across all possible warming levels in the database, it highlights where the minimum expected baseline relative extreme hazard today remains relatively low.

* **Assumption:** Neighbourhood disadvantage is higher where high social vulnerability and intensified hazards for extremely rare events converge.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** These absolute temperature values are statistically 90% likely to be higher than recorded in this field for this specific period.
* **Data Source:** Standardized from **UKCP18** current period probabilistic data.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
