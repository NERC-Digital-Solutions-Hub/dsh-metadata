#### Description

This **"All-Relative" Z-score** standardized the high-end projection for 5% annual-chance heat events at the end of the century against all other dataset scenarios. It identifies areas potentially facing catastrophic late-century relative extreme heat hazards relative to the entire dataset average if climate response is high under high global emissions.

* **Assumption:** Neighbourhoods with the highest relative maximum temperatures face the greatest challenge in protecting sensitive residents from heat stress.
* **Vulnerability Dimension:** Standardized input for **Hazard Exposure**.
* **Caveat:** Statistically, there is only a 10% probability that actual temperatures during such an event would exceed these values.
* **Data Source:** Standardized from **UKCP18** late-century maximum temperature data.

#### Interpretation

This indicator is a relative Z-score. Higher values indicate greater relative exposure to extreme heat compared to the full dataset, while lower values indicate comparatively reduced exposure.
